# English Year 5 · Teacher MikeSL

Interactive English revision for Year 5 pupils: basic vocabulary and grammar, Unit 2 (In Nature), listening, reading, writing, speaking practice, and a practice test.

All lesson audio is included as ready-made MP3 or WAV files in `audio/`. Pupils do not need an account or an API key. The speaking recorder uses the browser microphone only when a pupil chooses to record; recordings remain on that device and are not uploaded.

## Open the site

https://teachermikesl-cloud.github.io/english-year-5-revision/

The site is static. All internal links and media paths are relative so it also works in a GitHub Pages project subdirectory. Pushes to `main` deploy automatically through `.github/workflows/pages.yml`.

## Local preview

From this directory, run `python3 -m http.server 8000` and open `http://localhost:8000/`.
